DENTAL WORLD — V4 LOCAL 3D WEBSITE

This V4 packages the Dental World logo, doctor photos, and the 3D dental model data inside
the website folder. The site no longer depends on the NIH server to load the dental model.

FILES
- index.html
- assets/logo.jpeg
- assets/dr-sandeep-gupta.jpeg
- assets/dr-shaurya-negi.jpeg
- assets/dental-model.js

3D MODEL
The 3D viewer is a locally bundled educational upper-dental-arch model generated from
procedural tooth geometry. It is designed for reliable website deployment and marketing
visualization. The transparent aligner is an educational visual overlay and is NOT a
patient-specific appliance, treatment simulation, diagnosis, or clinical device.

THREE.JS
The site uses Three.js 0.180.0 and OrbitControls from jsDelivr at runtime. Therefore the
published website needs internet access for the Three.js library. The dental model and
all clinic images are local.
